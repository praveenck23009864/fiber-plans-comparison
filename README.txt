BROADBAND REFRESH — JioFiber, ACT Chennai, Hathway Chennai

1. Stop the API and any running scrapers. Extract ALL files beside your existing
   jio_fiber.db and .env in D:\airtel-plans-api (not inside a nested folder).
   These files do not overwrite your old main.py or scraper.py.
2. Install:
   .\venv\Scripts\python.exe -m pip install -r requirements_refresh.txt
3. Existing .env needs API_KEY, BROWSERBASE_API_KEY, BROWSERBASE_PROJECT_ID.
   Keep the real keys private. No new key is generated by this package.
4. Refresh:
   .\venv\Scripts\python.exe refresh_plans.py
5. Start the NEW API:
   .\venv\Scripts\python.exe -m uvicorn main_clean:app --port 8001
6. Open http://127.0.0.1:8001/docs and authorize with your own API_KEY.
   GET /api/jio/plans (optional category)
   GET /api/act/plans (city defaults to Chennai)
   GET /api/hathway/plans (city defaults to Chennai)
7. Existing load_test.py can test these same URLs.

Retry one provider:
   .\venv\Scripts\python.exe refresh_plans.py --provider jio
   .\venv\Scripts\python.exe refresh_plans.py --provider act
   .\venv\Scripts\python.exe refresh_plans.py --provider hathway

Use ONLY refresh_plans.py going forward. The old ACT script deletes Jio data.
Do not run adapters directly. They are imported by refresh_plans.py.

DATA AND SAFETY
Each plan in API data has exactly these fields:
provider,plan_name,price,speed_mbps,state,city,pincode,offer,offer_price,
offer_expiry,source_url,availability_verified

New authoritative table: broadband_plans.
Before replacing a provider, a timestamped SQLite backup is created.
Validation occurs before deletion. Delete/insert are one transaction.
A failed provider retains its old records; other providers may still succeed.
A first failed refresh has no new normalized records for that provider; its old
records remain in the old tables and are not exposed by main_clean.py.
After successful refresh, old-format records are cleared ONLY for that provider
(ACT/Hathway scoped to Chennai). Jio's plan_details and legacy plans tables are
assumed Jio-only, as in your supplied project. Their schemas are kept.
Switch to main_clean:app: old main.py reads those legacy tables.
Backups retain old data for recovery. Do not delete them until results are checked.

COVERAGE AND MEANING
Selectors come from your supplied scrapers, not a new live website inspection.
Jio: visits all six configured prepaid categories and their detail popups;
requires all categories to succeed before replacing Jio. Uses one Browserbase
session per category. A category can still exceed your account's session limit;
a failure retains existing Jio data. Watch the printed session link for errors.
ACT and Hathway: public Chennai grids only, not every promotional/checkout offer.
A stable grid is not proof of complete nationwide catalog coverage.
Carousel clones are deduplicated. Different price/duration options are retained.
Unknown values stay null. availability_verified=false means not verified,
NOT that the provider is unavailable. No phone/OTP/address forms are submitted.
Jio's general catalog does not prove Chennai or PIN-code availability, so state,
city and pincode are null. ACT/Hathway Chennai have state Tamil Nadu/city Chennai.
Speed is null for Jio vouchers without a speed (e.g. ISD/top-up).
Jio display names combine category and heading; metadata marks them generated.
Offer fields stay null: these supplied extractors do not reliably identify
plan-specific discount amounts/expiry. Promotional raw text is retained for review.
Hathway effective monthly prices must not be compared directly with Jio full
voucher prices. ACT billing period is not verified. Do not rank cheapest yet.
metadata_json retains price basis, validity when explicit, tax status and benefits.
raw_json retains extracted source details; last_checked records scrape time in UTC.
Neither metadata nor raw details are discarded to force a 12-field API.

VALIDATION
Offline checks cover normalization, duplicate conflicts, provider isolation,
empty-batch protection and rollback. Live Browserbase scraping has not been run
with your account. No .env or database was included in the download.
